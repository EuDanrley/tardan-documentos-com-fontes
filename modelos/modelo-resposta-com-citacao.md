# Modelo de resposta com citação

O assistente devolve sempre um destes três formatos. Use para conferir se a resposta veio completa.

## 1. Encontrou

```text
Resposta: [1 a 4 frases diretas]
Fonte: [DOC-xx — título, versão, data — seção/item] "trecho curto copiado do documento"
Atenção: nenhuma
```

## 2. Encontrou, mas há conflito ou versão antiga

```text
Resposta: Os documentos vigentes dizem coisas diferentes.
Fonte: [DOC-aa, versão, data — item] "trecho A"
Fonte: [DOC-bb, versão, data — item] "trecho B"
Atenção: CONFLITO ENTRE DOCUMENTOS — A CONFIRMAR com [dono do DOC-aa] e [dono do DOC-bb].
```

## 3. Não encontrou

```text
Resposta: Não encontrei isso nos documentos enviados.
Procurei: [assunto e documentos consultados]
Atenção: A CONFIRMAR com [dono do documento mais próximo ou "responsável a definir"].
```

## Como conferir uma resposta em 30 segundos

1. Abra o documento citado e vá à seção/item indicado.
2. O trecho entre aspas está lá, com as mesmas palavras?
3. A versão citada é a vigente (veja o campo Estado no cabeçalho)?
4. A resposta diz só o que o trecho diz, sem acrescentar prazo, valor ou condição?

Se qualquer resposta for "não", não use a resposta. Anote o caso no roteiro de testes.
